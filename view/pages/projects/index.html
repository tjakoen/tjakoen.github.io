01 · Product

Developer tools

For product teams and developers

Greenroom

Turn a live web app into repeatable browser checks. When something breaks, Greenroom bundles the trace, video, screenshots, logs, and a written summary so developers can reproduce the issue.

I built it as a local app and a deployable team platform. Its committed seeded report lets you inspect a passing run and an intentional failure without mistaking either for live customer data.

03 · Education

Teaching technology

For instructors and software engineering students

GitHub-Native Course Platform

I designed and built a course platform around the tools students use to learn software engineering. Course materials, submissions, feedback, and grading fit into a GitHub workflow instead of asking students to learn a separate system.

Built and run in production across several live university courses, covering hundreds of student repositories each term. The public source describes the operating model; the demo uses invented classes, with no student data or token.

I also teach these courses. See the courses, assessment approach, and badge criteria.
