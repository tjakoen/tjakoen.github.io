🥫 PANTRY · Dev-docs cockpit

One installable server for the whole stack.

PANTRY is the BREAD stack's installable developer-docs and AI cockpit: one app that composes the layers (BATCH, GRAIN, MILL, PROOF) into a single server you drop into any project. It is an app, not a fifth layer: the neutral, project-agnostic sibling of this portfolio. Two composition roots wiring the same stack is a stronger reuse proof than one. And it's AI-legible, not AI-powered: PANTRY runs no model itself, it just makes a project legible to one, through plain files and endpoints an agent can read without a UI.

What PANTRY gives a project

An app, not a layer

PANTRY doesn't sit in the batch → grain → mill → proof chain. It mounts all four, the same job this portfolio does, just without the personal branding.

The work board opens first

The installed app opens on the host project's plan board and working-with-AI surfaces. Its docs and the stack overview stay one step away, while the home page shows the work in that repo.

The project has two useful views

The server exposes /llms.txt and /knowledge.json for an AI agent. People can follow the codebase mind map at /map, and tools can read the same graph from /map.json.

The install kit reads the host repo

The kit adds the project instructions, standards, and initial plan structure. I tested it in a separate project, where it read that project's own plans folder.

From install to first use

PANTRY is installed inside the project you want to work on. These are the documented commands I used to scaffold its plan board, check the starter plan, and start the local cockpit.

1. Install in the host projectbun add -d @tjakoen/pantry@github:tjakoen/pantry#main
2. Scaffold and check the planbunx pantry initbunx proof check
3. Start the cockpitbunx pantry serveOpen the printed local URL. The board reads the host project's plans folder; PANTRY does not copy or replace the plan files.
