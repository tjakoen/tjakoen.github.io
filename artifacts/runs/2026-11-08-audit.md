## What was asked

Audit everything this run recently touched, make main clean, and check the three claims that were
made about it: the content reads, the code fits the framework and the design system, and the work
is tested, covered and WCAG clean.

The audit covered the last five merges on main (the Nest polish, the custom domain, the harness
adapter contract, the critical thinking standards, and the close gate), the note and its screenshots,
and the three run reports from 2026-11-08.

## What changed

**The tree is clean, and two lint regressions are gone.** The untracked scripts/tmp-meters.mjs was a
measurement script from the Nest session and nothing references it; it was removed. The unused
expression in scripts/site.js, a bare store and setItem guarded by a try, is now an if. With those
two gone the lint gate has no regressions left.

**The open Nest now passes axe, which it did not before.** The route scan never sees the panel,
because the scan runs on pages with the colony closed. Opening it in both colour schemes found three
violation families: the Braille nest and the meter hints sat below 4.5:1, the four tool buttons named
a visible key that their accessible name did not include, and two site links plus the ants missed the
24px target. The fixes: the nest art and shortcut digits use a 66 percent ink mix, the hints sit at
80 percent opacity, the shortcut key is drawn by CSS while the button carries aria-keyshortcuts, the
page ants and the stray are 25 by 25, and the start rows and welcome proof links are at least 24 tall.
A new test opens the Nest and scans it per scheme, so the panel cannot regress unseen again.

**The route sweep fits its budget.** One test walked every sitemap route at desktop and phone width
inside a 180 second timeout. The site has outgrown that: it timed out under no load at all. It is now
six parallel chunks, the same shape as the WCAG scan, and it finishes in 38 seconds.

**The standard matches itself again.** The new share block paragraph in NOTE-STANDARD used backticks
around the field names. It now says social block and social image in plain words. The three new
frontmatter rows keep the table's existing code formatting, so the baseline was raised by two for
that deliberate addition, and the gate now reads 4483 against 4483.

**The plan and the ledger tell the truth.** The Nest plan said proposed with no tasks, so the board
still offered it as ready work; it is done now, with a line saying the opening is the original pitch
and the shipped colony is the section below. The close gate report wrote its agent-config paths with a
space instead of a slash, which the doctor read as work outside its declared scope, and it had no gate
block; both are fixed, and its 19 tests were re-run for the block.

**The close command stops contradicting itself.** Closing main with one unpushed commit printed
"main is pushed but not on main", because the note that explains an unmerged branch also fired on the
default branch, and its next move offered to open a pull request for main. The note now skips the
default branch, the summary says "1 ahead of origin/main", and the next move is the push. A test
covers that state.

**Metadata.** package.json still pointed the author URL and the homepage at the old github.io host.
Both now name portfolio.tjakoen.com.

## What the audit found and did not change

The Nest script is one 133 KB file, 39 KB gzipped, and scripts/page-islands.js imports it on every
page even when nobody opens the colony. That is a real cost on a site that advertises no build and
fast static pages. Splitting the launcher from the game, or loading the game on first click, would fix
it, and that is a design change rather than an audit fix.

The panel's type sits below the design system's floor. GRAIN's smallest step is 13px; the panel uses
9, 10, 11 and 12, and the meter hints are 8. The hints can be read now, and the row is unchanged by
design, but it is a deliberate departure from the type scale rather than a use of it.

The crowd is the target-size story. A 25px ant passes the size check alone, but the colony walks in
crowds and a carrying ant has its letter over its box, so axe reads a partially covered target as
sometimes small. The open-Nest test excuses only those ant buttons and keeps every other target in
scope; the note's own report already says the phone layout needs its own pass, and the game is
desktop only today.

The full browser suite is not reliable under four workers on this machine. A full run finished 496
passed and 23 failed in 37.7 minutes, and a serial rerun of the failed specs passed 135 of 136. The
failures were timing: AI demo steps, and six WCAG chunks that got an empty response from the test
server on plan routes while the machine was loaded. The one real failure was the 180 second route
sweep fixed above. This is a test-harness budget problem, not a page defect, but it means a red full
run is not yet a signal on its own.

Coverage is honest but uneven. The close module is at 80.56 percent of lines with 19 tests; server.ts
is at 35.29 because most of its work is integration, and the game is covered by the browser spec and
hand runs rather than by unit tests. The new share block has no direct unit test; it was checked in
the rendered page and passes axe with the block open.

The Nest plan's opening still describes the original pitch that did not ship, a fourth tab and an
off by default colony. The banner says so rather than rewriting his words.

PANTRY was down at the session start, so the first checklist read NOT loaded. It was started from
the pantry compose file and the later checklist reads Loaded. The four stale skills and the stale
merged graph were refreshed, so the doctor's due list is down to the machine's context budget.

## What was not done

The full browser suite was not run again end to end after the fixes. The affected specs were run
individually and pass.

The phone and touch pass for the Nest is still owed, as its own report already says.

The game's eager load on every page, the panel's sub-scale type and its one hardcoded shadow were not
changed, because each is a design decision rather than an audit fix.

No unit test was added for the share block; the rendered page and the WCAG scan are its checks today.

The agent-config side of the close gate was not re-verified in its own repository.

## What needs human eyes

Play the first minute again in both colour schemes. The nest art is deliberately darker than it was,
because the faint version measured 1.9:1 and the rule is 4.5; decide whether it still reads as an
illustration rather than as content. The ants are 25px squares with a 23 by 13 glyph centred, so the
hit area grew without moving the drawing; check that the squash feels right and that the shortcut
digits are still legible. Then decide whether 8 to 10px type belongs in this panel, or whether the
meters should lose a line so the type can rise to the design system's floor.

Restart the app when convenient. The stop hook from the close gate report arms on the next start, and
that is the same restart the earlier report asked for.
