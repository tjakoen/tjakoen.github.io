# GRAIN, read by the audit, 2026-11-25

Two independent read-only children read this repo without seeing each other's work, which makes it the
estate's first real cross-check. They agreed on every material finding below; where they disagree on a
count, both numbers are given with the scope each was measured at. No gate was run and nothing was
rendered, so every claim is from reading code.

## Status by dimension

1. **Clean code.** Clean. Largest files are `catalog.ts` (651) and `diagram.ts` (544), both cohesive
   with colocated tests. `permutations` is exponential but bounded at the call site (six boundaries).
2. **DRY.** Two findings: the escaper in eight homes, the colour regex in three.
3. **Design system use.** The weakest dimension. Colour hygiene inside `components/` is genuinely clean
   (zero hex, held by `tokens.test.ts:36-52`), but the layer contract is breached, Layer 2 lacks the
   aliases that would fix a quarter of the breaches, the type scale is bypassed with no gate, the
   spacing scale has a hole two docs deny, and 19 published slots are dead.
4. **Efficiency.** One finding: `vocab-reference.ts` per-request parse. The catalog caches correctly.
5. **Error handling.** Two silent ones: the clipboard lie and the empty palette corpus, plus the
   focusable cap.
6. **Input validation.** One cast on a closed union; the rest of the contract guards are real.
7. **Types.** `any` confined to the lint rules; three non-null assertions in production code; no
   `@ts-ignore`.
8. **Tests.** Above the estate average. The lint engine asserts every rule has a failing fixture and
   no fixture names an unknown rule. Missing: the theme boot, four browser islands, and any
   two-directional token guard.
9. **Readability.** Code comments are unusually good and cite the lesson they came from. The drift is
   doc-side: seven stale docs claims, listed above.
