# Audit, second pass: the portfolio, 2026-11-25

A whole-estate audit ran earlier today and its report sits at
`../agent-config/audits/2026-11-25-estate-audit.md`. This file is the portfolio-scoped pass that this
repo's `AUDIT.md` runbook and `pantry_doctor` look for. It re-ran every gate, checked the first pass's
fixes against the code they changed, and replaced its name-based token scan with a definition-based
one. That last change is the reason a second pass was worth running: the first pass found two
undefined tokens by looking for the two names it already suspected, and the definition-based scan
found ten more.

Two honest method notes. The five-auditor fan-out in `standards/AUDIT-STANDARD.md` §4 failed again,
this time because the OpenCode Go plan hit its five-hour limit after the children launched; all five
returned that error and nothing else. So the repositories outside this one are still uncovered, and
§5 says which. The second note is that the lane that would have fixed it, a free model routed through
`routed_subagent`, refuses in this repository because the non-private-model clearance question from
24 November is still unanswered. Those two facts are the same finding twice.

   a name; `escapeHtml`, `SITE.origin` and the note-link rewrite each have one home.

   shortlink path at `src/server.ts:74`, low traffic and authoring-time content.
