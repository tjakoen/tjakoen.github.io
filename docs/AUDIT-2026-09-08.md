## Per-dimension status

Every dimension was hunted; none stayed silent.

1. **Clean code** — one major (`decide()` at 990 lines). The other large files are cohesive with small top-level functions and shallow nesting; no dead code found.
2. **DRY / atomicity** — five real duplications, every one with both homes named (page shell, note/event recompute, `Block` construction, `stripSlash`, `joinPhrases`, `waitForServer`). No repeated business logic — matching, routing, scoring each own one home.
3. **Design-system use** — four minor magic-value findings (desk pacing literals, the `FILL_SKIP` selectors, the screenshots palette, `PROOF_CSS_OVERRIDES`). The block/verb/span and route/tag/sender vocabularies all read from registries as designed.
4. **Efficiency** — the request-path re-parse and sequential awaits are the one real cost (major); the triple URL parse and the per-request token padding are minor. Desk-side fetches are all memoized; no sync fs in a request path; no regex built in a loop.
5. **Error handling** — one blocker (fixed) and one major (`desk-door` fetches). Every other catch logs or is a documented, intentional fallback. No unawaited promise, no unguarded `JSON.parse` in the checked scopes.
6. **Input validation** — model output is validated against closed sets everywhere it is consumed; the trust-boundary gaps are the four unvalidated boot-time JSON loads and the unchecked port env vars (both minor). The font/media path-traversal guards are correct.
7. **Types** — no `any`, no `@ts-ignore`. The findings are two duplicated `as unknown as` casts and a handful of guarded non-null assertions; `desk-door`'s DOM-shim casts are a deliberate, documented pattern.
8. **Tests** — the largest dimension. No coverage for `desk-door.ts`, `server.ts` routing (including the traversal guards), the builder model-build path, five tooling files, or the folded-note/plan/diagram allowlist feeders. A separate test-quality sweep found no flaky-by-construction sleeps, no live-network test, no port collision, and no bare existence-check standing in for a real assertion.
9. **Readability** — comments are extensive and accurate; the one wrinkle is `desk-reasoner`'s unnamed pacing literals reading as a contradiction of the file's own stated naming rule (counted under dimension 3).

## Follow-up — 2026-09-09

A second pass took the findings that were mine to fix (everything not on the uncommitted builder
branch). What closed, with the evidence:

- **`desk-door` silent fetches (major, fixed).** A `fetchArtifact` helper checks `r.ok` and the
  sitemap, notes and knowledge fetches log the URL on failure; a broken deploy now leaves a trace
  instead of a silent no-op. Commit `512bd31`.
- **The `lint-gate` blocker's class (closed).** The rising-count arithmetic is now one exported
  `risingCounts`, covered red and green by `tools/lint-gate.test.ts`; the CLI run is guarded behind
  `import.meta.main` so the test imports it without spawning the linters. Commit `512bd31`.
- **The per-request note re-parse (major, fixed).** `sortedNoteEntries` and
  `listEventCalendarEvents` memoize their disk read; one render no longer parses the corpus two or
  three times. Commit `42231cf`.
- **The duplicated page shell (major, fixed).** `shellPage` is exported and `/plans` and
  `/reference` build from it; both confirmed rendering unchanged with a screenshot. Commit `42231cf`.
- **The `server.ts` traversal-guard test gap (major, fixed).** The fonts/media containment check is
  extracted as `withinRoot` and covered by `server.test.ts` against `../`, absolute, sibling-prefix
  and dip-out-and-back payloads; a real boot serves legitimate media and 404s a traversal attempt.
  Commit `42231cf`.

**Deferred, with a reason.** The `decide()` decomposition (major, clean-code) is a ~990-line function
with no direct test coverage. Splitting it blind is how the desk breaks; it wants its own session
that lays down characterization tests for the action branches first, then extracts against them. Not
a patch. The remaining minors (the `stripSlash`/`joinPhrases` dedup, boot-JSON validation, the
`PROOF_CSS` magic dimensions, the port `NaN` check, the `waitForServer` dedup) are true and cheap to
defer, left as the next small-fix pass.

The full suite went from 630 to 645 tests across these two commits; `tsc`, lint-gate and the render
checks are green throughout.
