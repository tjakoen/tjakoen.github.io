## Course platform audit (github-native-course-platform, PUBLIC)

Cloned and audited 2026-07-29 (HEAD ed03ad1, 116 commits, sanitized showcase). Two serious results.

### HIGH, live public guardrail leak: real institution "HAU"

Sanitization missed the institution identifier. "HAU" (a real institution) is pervasive as real
GitHub org names, repo names, prose, and shipped app strings. This is exposed right now.

- `docs/examples.md:17-19` links REAL public orgs `HAU-6APSI`, `HAU-6ADET`, `HAU-6INTROWEB` and
  calls them "three real, public orgs." Identifies the school and the real course sections.
- `console/scripts/e2e-shots.mjs:27-29,113-115,264-265` and `e2e-cache.mjs:78` hardcode
  `HAU-6APSI` and real teacher repo names with section codes 2240/2203/2106.
- `console/scripts/fixtures/intents/*.md` bake "You are my grading assistant for the HAU platform"
  plus `HAU-6DEMO` clone paths.
- `console/site/lib/intents.mjs:134,207` ship "the HAU platform" into the running app.
- `console/docs/usage.md:17`, `console/docs/grading-guide.md:84`, and localStorage keys
  (`hau-crumb-first-run-v1`, `hau-grade-decisions-v1`, `hau-intent-sent-v1` across app.mjs,
  store.mjs, decisions.mjs) leak the acronym into shipped JS and export filenames.

Sanitization was inconsistent: the demo already uses a neutral `COURSE-ORG-WEB`, so the fix is to
push that same neutralization through console/, scripts/, fixtures/, and docs/. This is the
sharpest live breach in the whole audit and should be first.

Clean otherwise: no student data (the demo gradebook uses famous computing figures, labeled
fictional), no secrets or tokens (docs name which secrets to set, no values), README-STANDARD
passes.

### HIGH, teaching-note stats are unverifiable against the public repo

`how-i-use-ai-in-teaching.md` claims 537 commits, ~47k lines, 17,700 md / 23,800 code, 58 tests,
103 bot commits. Against the public repo, every number differs:

| Metric | Note claims | Public repo (HEAD ed03ad1) |
| --- | --- | --- |
| Commits | 537 | 116 |
| Bot / AI commits | 103 | 0 (all 116 authored by the owner, no Co-Authored-By) |
| Total tracked lines | ~47k | 20,911 |
| Markdown lines | 17,700 | 3,989 |
| Code lines | 23,800 | 16,542 |
| Tests | 58 | 0 verifiable (a check:intents script + a Playwright screenshotter) |

The public repo is a sanitized showcase (subset), so the 537/47k/103 figures almost certainly
describe the PRIVATE production monorepo, a larger universe. The mismatch is expected, but the
notes present these as the platform's stats with no public-vs-private flag, so a reader cannot
verify them. This is an OWNER decision (see Phase 0), not an auto-rewrite: either cite the public
showcase numbers with a snapshot flag, or keep the private figures but mark them a dated snapshot
and note the public artifact is a subset. Do not leave them stated as current verifiable fact.
