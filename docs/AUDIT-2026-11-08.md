# Repo audit, 2026-11-08

Five read-only auditors read the repo by bounded scope: server and content, the AI subsystem, client
scripts and views, content and standards, and tooling with tests and CI. Each worked the same nine
dimensions and returned file:line findings. This page is the synthesis: the gate was green before the
pass and after it, every finding below is either fixed in this pass or deferred with a reason, and the
measurements in the gate block are from the current tree.

The largest finding was a class, not an instance: five checks could report a pass without doing the
work. The WCAG route scan could scan zero pages and stay green, the screenshot tool exited 0 after a
failed capture, the heartbeat swallowed exit 2 and closed the findings issue, the export dropped badge
routes on a corrupt index, and the component preflight scanned nothing when a template root was
missing. All five now refuse to report success when they scanned nothing, or fail loudly.

## Per-dimension status

1. **Clean code.** Findings, mostly deferred. The 1,809 line content.ts, the 947 line builder boot, the 723 line deterministicTurn and the 1,650 line nest start need decomposition plans. Small dead code and stale comments are fixed.
2. **DRY.** Findings, partly fixed. The drifted trap widget is aligned; six component tables, four normalizers, the demo ladder and the doubled date/sync helpers are deferred.
3. **Design system.** Clean in scripts and view CSS, which use tokens; the Nest panel's sub-scale type and three badge hues are named as design decisions, not fixed here.
4. **Efficiency.** Findings. The SSE idle timeout is fixed; the eager game, per-frame scans, per-request calendar rebuild and 359 KB JS are deferred to a performance pass.
5. **Error handling.** The strongest result. Six silent-pass or silent-failure paths were fixed at their source, including the five checks that could claim success without running.
6. **Input validation.** The shortlinks prototype lookup and the PORT parser are fixed; the client-supplied session id and the store-shaped JSON on the mail and calendar pages are deferred.
7. **Types.** No any or ts-ignore in the AI subsystem; the remaining items are non-null trust in content.ts and untyped figure hosts.
8. **Tests.** Two tests that could pass while asserting nothing are fixed (WCAG route guard, ordered feed) and the CI-red placement test is fixed. Coverage gaps remain in canvas-dom, export route enumeration, verify-export and the server handler call sites.
9. **Readability.** Small corrections landed (header counts, dangling comment, stale comments). The decomposition findings carry the rest.

## Could this class have been designed out?

Yes, and it was. The silent-pass class now has a gate-shaped answer in each tool: the WCAG scan
refuses an empty route list, link-lint refuses a zero-file run, screenshots and the heartbeat exit
non-zero on failure, and the export fails on a corrupt badge index instead of shipping fewer routes.
The same shape is the audit's own rule about a check that passes when it could not run.

## Deferred, with reasons

- **Decomposition** of content.ts, builder-canvas, desk-reasoner and the nest script needs a plan per
  module, not an audit patch.
- **Session identity** on the AI door is an architecture change: server-issued id bound to a cookie.
  The current ids are per-tab UUIDs that never appear in a URL, so the practical exposure is low.
- **The consolidated figure widgets** need one mount module; only the drifted click count was fixed.
- **Page-island storage and HTML restore** touches grain's markdown allowlist; it wants a shared
  restore helper rather than a local sanitizer.
- **Export and verify-export** need a two-way route check and a watched child process, which is a
  design of the export gate rather than a line.
- **The 359 KB JS budget and the panel's type scale** are design decisions for the owner.
- **The CONTENT-BACKLOG date** is the owner's publishing record.
