# Portfolio audit, 2026-11-07

This pass asked three questions of the site. Do its data and pages connect? Is every outside idea
credited? Do the pages that feature a project match where that project stands today? Each finding
below names the command or file that settles it, so a later session can rerun the check rather than
trust this page. Nothing was edited to produce it.

## What holds

- **Links resolve.** The link linter reports 58 rendered files and no dead relative links. Every
  link from a hand-authored page to a note or a calendar post points at a file that exists.
- **The headline numbers agree.** The teaching load reads 150 to 300 students in the CV data, the
  About page, the desk facts and all three notes that quote it. The contradiction logged on
  2026-07-29 is closed.
- **Outside ideas are credited where they are used.** The goldfish reviewer is credited in
  [AI-DEVELOPMENT](../standards/AI-DEVELOPMENT.md) and in [NOTICE](../NOTICE). C.R.I.S.S.P. is
  credited in [LOOP](../standards/LOOP.md), in [LOOP-SOURCES](LOOP-SOURCES.md), and in PANTRY's
  own NOTICE, which is where its code was adapted.
- **Badges are complete.** All 737 issued badges carry an Open Badges file naming the issuer. The
  .md files without one are class-level badge definitions, which is expected.
- **The PROOF page tells the truth about itself.** It says the live board ships in the package but
  is not mounted here, and the server code confirms that.

## Findings

### 1. The flagship note's receipt does not match the git history (owner call)

The note [ten-times-zero](../content/notes/ten-times-zero.md) says, at lines 18 and 286, that the
503 commits of 2026-08-22 were each co-authored with an AI, and it presents that as pulled from
this repo's git history. The history shows 502 commits up to that date, which matches the count.
It shows only 21 commits in the whole repo, out of 785, carrying a co-author trailer.

The claim may still be true in practice, since much of the early work predates the trailer habit.
As written, though, a reader who runs the obvious check gets a different answer from the one the
page promises. Either reword the claim to what the history proves, or say plainly that the trailer
came later than the practice. This is the owner's sentence, so it was not changed.

Check it with: git log --until=2026-08-22 --oneline | wc -l, then
git log --format=%B | grep -ci "co-authored-by: claude".

### 2. The same note's numbers are eleven weeks old

The note's living snapshot was last measured on 2026-08-22, at 503 commits. The repo now has 785.
The note does date the figure, so it is not false, but a page calling itself a living snapshot has
gone stale. Remeasure it, or relabel it as a dated marker.

### 3. The layer pins are one release behind

The site locks grain 0.1.27, mill 0.4.0 and proof 0.1.4. GRAIN released grain 0.1.28, mill 0.4.1
and proof 0.1.5 today, carrying the WCAG 2.2 AA fixes. Run deps:refresh, then the full gate
including the e2e suite, because component markup changed upstream. The lock file also still
lists grain 0.1.21 and 0.1.23 and mill 0.2.2 as transitive entries.

### 4. The GRAIN page says nothing about accessibility

Nothing on the GRAIN showcase page or in its docs mentions WCAG or accessibility. The release that
landed today is the strongest claim GRAIN can make about its components. Once the pins move, it
belongs on the page and in the GRAIN docs, as a sentence that names the standard and what was
tested, with no badge on it.

### 5. NOTICE names a path that no longer exists

[NOTICE](../NOTICE) says the written content lives under notes/. The notes live under
content/notes/, beside content/events/, which also holds prose and photographs. The licence
boundary should name the real directories.

### 6. The lint gate has drifted from its baseline

The lint gate reports two small regressions. The prose has five more backticks than the baseline
allows, and [issue-badges.test.ts:211](../tools/issue-badges.test.ts) declares a variable that
shadows one in the outer scope. Neither is serious, but both should be fixed rather than written
into the baseline.

### 7. Doc freshness, for the record

The layer docs were last touched on these dates: GRAIN, BATCH, PROOF and PANTRY on 2026-11-01,
MILL on 2026-10-12, and CRUMB on 2026-10-09. The only upstream changes since then are the
accessibility release and a fix that makes the crumb and proof checks fail on a directory they
could not read. No doc contradicts either change, so nothing is stale yet. The PANTRY getting
started page installs the package before calling bunx pantry, which avoids the unscoped name
collision recorded earlier.
