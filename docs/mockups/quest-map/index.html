4 · Lesson mode: the note keeps its words, the sidebar becomes the quest book

Model Mines · Quest 1 · Stop 2 of 4 · Rate limits are a design input

I Ran Out With Hours Left

It was a Tuesday afternoon and the usage meter said I had spent the week's allowance on day two. I had planned for tokens the way I plan for coffee: assume it will be there.

A limit you hit mid-task is not a billing problem. It is a design input, and the only question is whether you chose the layer that handles it or discovered it at the worst possible moment. So I stopped asking which model is best and started asking which model is enough for this step.

That reframing is the whole note. The rest is how the routing works once you accept it.

6 · Notes and lessons: many to many

One note, several lessons

  • Lesson B: Building it (headings 4 to 7)
  • Lesson C: Keeping it honest (headings 8 to 10)
A note too long for one sitting is cut at its headings. Each lesson gets its own recording and stops.

One lesson, several notes

Loop Forest · Lesson 2: the loop on three harnesses
  • Segment 1: one-loop-three-harnesses, headings 2 and 3
  • Segment 2: loop-setup, headings 1 and 2
  • Segment 3: back to the first note, heading 5
A lesson is an ordered list of segments. Each segment is a note plus a heading range, so paired notes teach as one.

Quest, lesson, segment, note

quest      a stop on the map
 lesson    one recording, ordered
  segment  note + heading range
   stop    runes, trial, XP
The sidecar file belongs to the lesson, not the note, so a note can appear in many lessons and stay untouched.

A rune is not a badge. A rune is a concept, one per idea a stop teaches, and it lives in the Codex. A badge is earned by finishing a region, so it needs the trials, not just the runes. The badge page borrows the runes as its skill list, the way a certification lists skills, and that is the only place the two meet. Badges reuse the existing badge-class machinery and medallion. Optional cosmetic achievements, such as collecting every Mines rune, can exist but are never badges.
