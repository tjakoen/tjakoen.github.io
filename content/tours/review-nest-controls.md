## screen
- at: /notes/the-site-has-ants
- status: needs-verification
- review: The note points readers to the terminal. On a wide screen, the command reveals the ant in the status bar.
- verify: In a fresh browser session, type nest with focus on the page and check that no ant appears. Run nest in the terminal, then click the ant in the status bar.

## nest-controls
- at: /notes/the-site-has-ants
- status: needs-verification
- review: The sidebar uses icons, with a description for each on hover. Use Page Links lets you browse while the colony keeps running.
- verify: Hover the tools, then try a link with Squash selected. Wait for a dotted trail, select Wipe Trail, and drag across it. The ants should scatter and find another trail or head home. Select Use Page Links and check that the link works.

## anchor:what-the-ants-actually-do
- at: /notes/the-site-has-ants
- status: needs-verification
- review: Mini hills can fit in the space left by stolen letters. Builders favor gaps in view and spread out from existing hills.
- verify: Narrow the desktop window and leave a colony feeding until its stores fill. A mini hill should fit without covering readable text. If one grows in stolen text, press Restore Page. The letters should come back and clear that hill.
