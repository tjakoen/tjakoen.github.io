# The words you will hear

Status: DRAFT script for Tjakoen to read aloud and edit. Not yet read or checked by him.

Same format as the Harbor script: one idea a beat, about 20 to 45 seconds, names the phrase in the note that lights up, and adds the story, the why or the practice instead of repeating the page. This is a journey and an invitation, not a tutorial. The words this path uses, one plain line each, and where to go when a word is missing.

## Stop 1: What answers you

**Beat 1**
highlight: intro | that's my fault and not yours

I used these words for months before I wrote any of them down. My older notes say harness and loop and session as if you were in the room when I learned them. If a word has been going past you, that is my fault and not yours.

**Beat 2**
highlight: the-bottom-layer-what-answers-you | It has no memory of you and no access to your files.

Start at the bottom. The model is the AI itself. It reads text and writes text. It has no memory of you and no access to your files. It only answers. What you send it is a prompt, and it reads in tokens, small pieces a bit smaller than a word.

**Beat 3**
highlight: the-bottom-layer-what-answers-you | Everything the model can see right now

Context is everything the model can see right now. It has a size limit, and when you fill it the model starts losing the early parts. That is why a long session goes wrong, and why a fresh session often works better.

**Digest:** A model only answers. It has no memory of you and no access to your files. | A prompt is what you send it, and tokens are the pieces it reads and writes in. | Context is everything the model can see right now, and it has a size limit.

**Trial:** Pick the word from this stop you would find hardest to explain to a friend, and write your own one-line version.

**Runes:**
intro | that's my fault and not yours
the-bottom-layer-what-answers-you | Everything the model can see right now

## Stop 2: What lets it work on your project

**Beat 1**
highlight: the-middle-layer-what-lets-it-work-on-your-project | The model thinks, and the harness is the hands.

The middle layer is what lets it work on your project. A harness wraps the model so it can read your files, edit them and run commands. The model thinks, and the harness is the hands. A model inside a harness, working through a task, is an agent.

**Beat 2**
highlight: the-middle-layer-what-lets-it-work-on-your-project | It forgets everything afterwards

A session is one run of an agent. It forgets everything afterwards, so whatever you want to keep has to live in the project. That one fact explains most of the rest of this path.

**Beat 3**
highlight: the-top-layer-what-you-set-up-around-it | It's the contract you write for your own project

The top layer is yours. A plan, a skill, and a standard, which is a written rule the agent reads before it works. It is the contract you write for your own project, and the part that sounds like you. The loop is the workflow around all of it.

**Beat 4**
highlight: the-top-layer-what-you-set-up-around-it | figure: How the words stack

Here is how they stack. You give a prompt to an agent. The agent is a model inside a harness. And your project, the plan, the skills and the standards, is what the agent reads each session.

**Digest:** A harness wraps a model so it can read files, edit them and run commands. | An agent is a model in a harness working through a task. A session is one run of it, and it forgets afterwards. | The plan, the skills and the standards are what you set up around it.

**Trial:** Ask your AI to name which harness and which model you are talking to right now, and where your project keeps its plan.

**Runes:**
the-middle-layer-what-lets-it-work-on-your-project | The model thinks, and the harness is the hands.
the-top-layer-what-you-set-up-around-it | It's the contract you write for your own project

## Stop 3: When a word is missing

**Beat 1**
highlight: where-the-longer-list-lives | the glossary

There are more words than these. I keep a glossary that my own agents read before they write anything, and some entries are about my setup, so skip those.

**Beat 2**
highlight: where-the-longer-list-lives | Explain this term as if I were new

When you hit a word that is on neither list, do what I do. Ask your agent to explain this term as if you were new, and to say where it shows up in your project. It is very good at that.

**Beat 3**
highlight: your-turn | Treat the list as a map for getting started, and expect to redraw it.

And where I might be wrong. These are one person's definitions from daily use, and the field renames things every few months. Treat the list as a map for getting started, and expect to redraw it.

**Digest:** There is a longer glossary, and some entries are specific to my setup. | When a word is missing, ask your agent to explain it as if you were new. | These are one person's definitions. Believe your tool when it disagrees.

**Trial:** Pick the three words you would find hardest to explain, ask your AI to explain each using your portfolio as the example, then write your own one-line version in your roadmap.
