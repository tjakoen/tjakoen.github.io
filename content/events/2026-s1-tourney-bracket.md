## What it is

Create a tournament, add players, and the app builds a single or double elimination bracket, takes scores as matches finish, and keeps stats across events. It was built to run the author's own tournaments.

Built with Node, Express and PostgreSQL.

## Why it is here

Built for the author's own events first, which is the most reliable way to build something good. The free server sleeps, so give it a minute on the first visit.
