*A final project from Introduction to Web Development, 2026 first semester. Part of [Four websites built with nothing but HTML, CSS and JavaScript](/calendar/2026-s1-introweb-students).*

## What it is

Memora is a flashcard site for students who want something faster than paper cards and cheaper than a subscription. Build a deck, study it with a flip-card view, and keep track of how many cards you still need to get right.

Built with HTML, CSS and JavaScript.

## Why it is here

The landing page could pass for a real product's, and that is plain HTML, CSS and JavaScript, which is all this course allows. It was built by a team of four, and it reads like one person's idea, which is the hard part of group work.
