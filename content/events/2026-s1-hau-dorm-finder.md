*A final project from Introduction to Web Development, 2026 first semester. Part of [Four websites built with nothing but HTML, CSS and JavaScript](/calendar/2026-s1-introweb-students).*

## What it is

HAU Dorm Finder gathers dormitory options near campus in one place, so a student can compare price, walking distance and amenities instead of scrolling Facebook groups and asking around. The listings are sample data for now.

Built with HTML, CSS and JavaScript.

## Why it is here

It is the clearest local problem in the class, and every incoming student has it. The team was also upfront in their own log about how much AI help they used, and I respect that more than a project that pretends it had none.
