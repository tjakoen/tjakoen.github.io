## What this badge attests

HTML structure and semantic markup, CSS layout with grid and flexbox, responsive design and visual hierarchy following web standards. Covers modules 1 to 5, mapped to course outcomes CO1 and CO2.

## Technologies

HTML semantics, CSS grid and flexbox, and responsive layout.

## Where it sits

Basic Programming in Web Development carries two badges. Its prelim badge, Web Foundations, covers HTML and CSS foundations for responsive pages. Its midterm badge, Interactive Web Pages, covers client-side JavaScript and interactive pages. This is the prelim badge.

## How it is earned

The holder was an active student in the prelim block of Basic Programming in Web Development (6INTROWEB), section 2106, and completed real coursework in it. The badge is awarded on completion, meaning submitted work with content rather than a grade cutoff. Each recipient's award is a separate, verifiable credential opened from their own badge link. This page states the criteria every recipient met, not a list of who met them.
