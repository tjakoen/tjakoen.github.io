## What this badge attests

Node and Express REST APIs and PostgreSQL data modelling, building and deploying a backend service. Covers modules 4 to 5, mapped to course outcomes CO1 to CO3.

## Technologies

Node, Express, REST APIs, PostgreSQL data modelling and a cloud deploy.

## Where it sits

Application and System Integration carries two badges. Its prelim badge, Frontend Design with Cloud, covers JavaScript, React and deploying a front end. Its midterm badge, Backend Development with Cloud, covers Node, Express, PostgreSQL and deploying a backend service. This is the midterm badge.

## How it is earned

The holder was an active student in the midterm block of Application and System Integration (6APSI), section 2209, and completed real coursework in it. The badge is awarded on completion, meaning submitted work with content rather than a grade cutoff. Each recipient's award is a separate, verifiable credential opened from their own badge link. This page states the criteria every recipient met, not a list of who met them.
